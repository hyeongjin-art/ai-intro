용어 ①02 — AI의 두뇌
// TERM 01

LLM Large Language Model · 대규모 언어 모델

엄청난 양의 글을 읽고 "다음에 올 단어"를 확률로 예측하는 AI.
ChatGPT · Claude · Gemini의 두뇌가 바로 이것. 한마디로 — 초거대 자동완성.

"오늘 점심은 ______"

김치찌개
38%
뭐 먹지
26%
패스
11%

⚠️ 단, LLM은 '두뇌'일 뿐 — 우리가 실제로 만지는 건 두뇌에 연결된 '창구'다. 다음 장에서 계속 →

용어 ②03 — 세 가지 창구
// TERM 02–04

창구가 다르면, 경험이 다르다

G U I 🖱️

Graphical UI

버튼·아이콘·창을 마우스로 클릭해서 쓰는 화면.
예) ChatGPT 웹, 카카오톡

비유 → 직접 가는 매장
C L I ⌨️

Command Line UI

글자(명령어)를 키보드로 입력해서 쓰는 방식.
예) claude codex

비유 → 주문서 쓰는 드라이브스루
C M D 🏢

명령 프롬프트

CLI 명령을 입력·실행하는 '까만 창' 환경의 하나.
윈도우는 CMD/PowerShell, 맥은 터미널.

비유 → 드라이브스루가 있는 건물

GUI = 매장 / CLI = 주문서 / CMD = 건물. 같은 가게(AI)라도 이용 방법이 다른 것뿐!

정리05 — 용어 한 장 요약
// CHEAT SHEET

5개 용어, 한 장으로 끝

용어한 줄 정의일상 비유
LLM말을 배운 AI 두뇌🔮 초거대 자동완성
GUI클릭하는 화면🏪 매장 방문
CLI명령어로 쓰는 방식📝 주문서 직접 작성
CMD명령어 입력하는 창(환경)🏢 드라이브스루 건물
Local내 PC에서 직접 실행🍳 집에서 직접 요리

이 다섯 개만 알면, AI 기사·유튜브가 갑자기 들리기 시작한다.

작동 방식06 — 공통 원리
// HOW IT WORKS

두뇌는 하나, 창구만 다르다

🙋 나 질문 = 프롬프트
🖱️ GUI 창구채팅창에 입력
⌨️ CLI 창구명령어로 입력
🧠 LLM 다음 단어를 예측·생성
💬 답변 또는 작업 결과

'화면 방식'과 'AI 모델'은 서로 다른 층위다.
GUI든 CLI든 속에 든 두뇌(LLM)는 같다 — 다른 건 말 거는 방법뿐.

챗봇형07 — GUI로 쓰는 AI
// MODE 01 — 챗봇형 (GUI)

대화하듯, 누구나 바로

1설치 없이 시작 — 웹사이트·앱 입력창에 그냥 묻는다.
2채팅 형태 — 질문 → 서버의 LLM 호출 → 화면에 답 표시.
3파일·이미지도 클릭으로 — 첨부 버튼 하나면 끝.
→대표주자: ChatGPT 웹 · Claude.ai · Gemini 앱

작업형08 — CLI로 쓰는 AI
// MODE 02 — 작업형 (CLI)

명령하면, 직접 해치운다

1터미널에 명령어 입력 — AI가 내 컴퓨터의 파일·프로그램에 직접 접근해 작업 수행.
2자동화·반복작업의 강자 — 수십 개 파일을 한 번에 처리, 스크립트로 재사용.
3배움이 필요하지만 — 익히면 업무 속도가 차원이 달라진다.
→대표주자: Claude Code · Codex CLI
terminal — 작업형 AI
user@pc ~/문서 $ claude "이 폴더 엑셀 30개 요약해줘"
⠋ 폴더 스캔 중… 엑셀 파일 30개 발견
1~10월 매출 데이터 읽기 완료
월별 합계·증감률 계산 완료
요약본 생성 → 월별요약_2026.xlsx
★ 완료! 30개 파일 → 1개 요약본 (2분 13초)
비교09 — 챗봇형 vs 작업형
// HEAD TO HEAD

경쟁이 아니라 역할 분담

🖱️ 챗봇형 (GUI)⌨️ 작업형 (CLI)
난이도쉬움 — 클릭이면 끝학습 필요 — 명령어
진입 장벽낮음높음
자동화·반복약함강함 ★
내 파일 직접 조작제한적 (업로드)강함 — 직접 읽고 수정
어울리는 일가벼운 질문·글쓰기반복·대량·개발
대표 예시ChatGPT 웹Claude Code

가끔 질문은 GUI · 반복·대량 작업은 CLI — 골라 쓰면 된다!

활용10 — 내일 당장 써먹기
// REAL WORK, REAL GAIN

업무 활용 2가지 시나리오

🖱️ ① 챗봇형 — 이메일·보고서 초안
"이런 상황인데, 정중한 거절 메일 좀 써줘"
HOWChatGPT 웹에 상황을 설명하고 초안을 받는다 → 내 말투로 다듬는다.
WHO누구나, 오늘 당장 가능. 준비물은 없음.
⚡ 효과 — 글쓰기 시간 절감, "어떻게 쓰지?" 막힘 해소
⌨️ ② 작업형 — 파일 일괄 처리
$ claude "이 폴더 엑셀 30개 읽어서
  월별 요약본 하나로 만들어줘"
HOWCLI AI가 폴더의 파일을 직접 읽고 계산·요약해 결과 파일을 생성.
WHO반복작업에 시달리는 사람. 조금 배우면 평생 무기.
⚡ 효과 — 사람이 하루 걸릴 반복작업을 수 분에
